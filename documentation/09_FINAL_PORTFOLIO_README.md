# NEXORA SALES & OPERATIONS PERFORMANCE INTELLIGENCE

A premium corporate Power BI portfolio project demonstrating sales intelligence, target performance, regional analysis, customer analytics, and inventory risk management.

## Tools
- Microsoft Power BI Desktop
- Power Query
- DAX
- TMDL
- Excel/CSV source data

## Model
11-table star schema:
- 8 dimensions
- 3 facts
- 12 intended relationships

## Business questions
- How is revenue performing against target?
- Which regions, categories, channels and products drive performance?
- Where is margin under pressure?
- Which inventory positions require attention?
- Which customers and segments contribute most value?

## Data integrity
The source package was independently checked for key integrity, referential integrity, date continuity and transaction-level financial reconciliation.

## Portfolio positioning
This is a self-directed portfolio project using supplied synthetic business data. It must not be represented as paid client work or as a real Nexora client engagement.

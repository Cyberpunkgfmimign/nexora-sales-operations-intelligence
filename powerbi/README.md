# NEXORA Power BI Project

The final PBIP/PBIR/TMDL project is maintained as a distributable package alongside this repository.

## Project contents
- PBIP project definition
- Semantic model definition
- TMDL tables and relationships
- PBIR report definition
- Five report pages and their visual definitions
- Registered NEXORA cyberpunk theme

## Reproducibility and data integrity
The original source data is not committed to this public repository. The source dataset remains read-only/source-of-truth material. Local Power BI cache and environment-specific `.pbi` files are intentionally excluded from the distributable package.

## Open in Power BI
Open the `.pbip` project file in a current Power BI Desktop release with PBIP support enabled. If the source connection is unavailable on another machine, reconnect it to an authorized copy of the source workbook without modifying source values.

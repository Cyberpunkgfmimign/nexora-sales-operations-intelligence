# Upwork Portfolio Description

## NEXORA — Sales & Operations Performance Intelligence

Designed and built a five-page Microsoft Power BI business intelligence report for sales and operations analysis.

### What the project covers

- Revenue and gross-profit performance
- Gross margin and average order value
- Target achievement and variance
- Monthly growth trends
- Regional, category and channel performance
- Sales representative performance
- Product performance
- Customer segments and customer value
- Inventory value and stock on hand
- Low-stock and stockout monitoring
- Inventory risk and slow/fast movers

### Technical implementation

- Microsoft Power BI
- DAX
- Power Query
- Star-schema data modeling
- Interactive slicers and visual interactions
- KPI design
- Business intelligence dashboard design
- Data validation and reconciliation
